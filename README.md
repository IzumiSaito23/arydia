# 阿瑞迪亚 · 旅伴 网页版

网页版入口：https://izumisaito23.github.io/arydia/

当前维护版本 3.8.27。包含中文卡牌文本检索、角色成长与技能、团队及个人背包、垂钓日志、地图与游戏音乐。存档保存在设备的浏览器中，更新前可在设置中导出备份。

首次游玩不建议使用地图功能。网页包含卡牌、地图与剧情剧透，请根据自己的进度查阅。卡牌文本经过手工初步校对，仍可能有错字或遗漏，请以实体卡牌和说明书为准。

## 发布维护

本仓库仅用于网页版维护与 GitHub Pages 发布，不上传安卓安装包、安卓工程或签名材料。发布任务也不创建安卓 Release。

网页代码位于 `web/dist`。原有图片与音乐保存在 `web/assets.zip`，本次新增浏览器素材保存在 `web/maintenance-assets`。`web/publish-manifest.json` 记录网页文件的校验值；发布时自动还原素材、校验文件与备份兼容性，然后只部署网页文件。

所有功能免费。游戏原有图文和音乐的权利归各自权利人所有。
